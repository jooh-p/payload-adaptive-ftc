# Active Adaptive Control for a Quadrotor with an Unknown Payload under Complete Rotor Failure — Reproduction Code

Reproduction code for the paper *Active Adaptive Control for a Quadrotor with an Unknown Payload under Complete Rotor Failure* (IEIE 2026 Fall Undergraduate Paper Competition).

A quadrotor carries a bottom-mounted payload of unknown mass. The controller estimates the payload mass during hover, and when one rotor fails completely it injects a feed-forward thrust matched to the estimated mass and switches control parameters to reduce altitude loss. The baseline controller and the drone model are taken unchanged from the public repository of Beyer et al.

## Requirements

- MATLAB R2026a or R2026b, Simulink, Curve Fitting Toolbox (both releases give identical results to 12 significant digits)
- On Windows, clone to a **short path** (e.g. `C:\pftc`). The build fails if a path of the C files generated by Simulink exceeds 260 characters.

## Run

```matlab
cd scripts
verify_release_IRIS      % six representative cases, about 3–4 min
```

To run a single case:

```matlab
cd scripts
addPathFtc
ctx = ctx_current_IRIS();
r   = run_case_IRIS(ctx, '다', 0.340, 2);   % proposed controller · 340 g payload · rotor 2 failure
```

`kind` is one of

| `kind` | Meaning |
|---|---|
| `'가'` | baseline controller, no payload (reference) |
| `'나'` | baseline controller, with payload (non-adaptive) |
| `'다'` | proposed controller, with payload |
| `'무고장'` | baseline controller, with payload, no failure |

## Expected results (`verify_release_IRIS`)

| Case | Initial drop [m] | Late-phase max drop [m] | Max tilt [°] | Estimated mass [g] |
|---|---|---|---|---|
| 가 0 g, rotor 2 | 5.150 | 0.636 | 20.72 | – |
| 나 340 g, rotor 2 | 5.642 | 5.143 | 61.18 | – |
| 다 340 g, rotor 2 | 1.904 | 0.194 | 19.37 | 337.9 |
| 다 100 g, rotor 2 | 1.086 | 0.021 | 17.92 | 99.6 |
| 다 340 g, rotor 3 | 1.803 | 0.195 | 20.20 | 337.9 |

Metrics — the rotor fails at 35 s. The initial drop is the altitude lost down to the lowest point in 35–45 s. The late-phase max drop and max tilt are taken over 45–77 s.

## Contents

| Path | Contents |
|---|---|
| `scripts/` | Proposed controller and evaluation harness. All experiment settings are in `cfg_current_IRIS.m` |
| `models/QuadcopterSimModel_Loiter_FTC_dseg.slx` | Experiment model (Simulink model with detection and injection blocks added) |
| `data/` | Detection constants, payload-free reference motor speeds, reach-error reference point |
| `modules/` | LADAC library and airframe data from the original authors |
